# Chat between connected members Implementation Plan

**Goal:** Connected members send each other text messages, refreshed by the member, with unread marks.

**Spec:** `docs/specs/2026-10-23-29-chat.md`

**Architecture:** One closed table `messages`; one internal delivery step `deliver_message` (checks connection, rate limit,
length) used by `send_message` now and by posts (#30) later; five member functions. Server action for sending; pages
`/messages` and `/messages/[memberId]`; header unread number; Message button on profiles and connection lists.

## Tasks (tests first)

1. **Database** (`supabase/tests/messages.test.sql`, `supabase/migrations/20261023150000_messages.sql`).
2. **Form and action** (`src/lib/messages/form.ts`, `src/app/messages/actions.ts`, tests).
3. **Screens** (`/messages`, `/messages/[memberId]`, header, profile and connection links, `copy.ts`, rendering tests).
4. **Checks and QA:** lint, unit, DB, build, tsc; browser QA with two local members at desktop and 375px.
